# SmartCart – Customer Segmentation Using Unsupervised Machine Learning

## Project Overview

SmartCart is a customer segmentation project that uses unsupervised machine learning to identify different groups of customers based on their demographics, purchasing behaviour, spending patterns, and platform engagement.

The project analyzes customer data to discover hidden patterns and help an e-commerce business understand its customers better. These insights can support personalized marketing campaigns, customer engagement strategies, and customer retention.

## Problem Statement

SmartCart has a dataset containing 2,240 customer records and 22 attributes. The dataset includes customer demographics, income, product spending, purchase frequency, website activity, and customer feedback.

Using the same marketing strategy for every customer may result in missed opportunities and ineffective customer engagement.

This project addresses that problem by applying clustering algorithms to group customers with similar characteristics and purchasing behaviour.

## Objectives

- Analyze customer demographics and purchasing behaviour.
- Identify meaningful customer segments.
- Understand customer spending and purchasing patterns.
- Compare different clustering approaches.
- Visualize customer groups using dimensionality reduction.
- Generate cluster summaries to support business decisions.

## Dataset Description

The dataset contains 2,240 customer records and 22 original attributes.

The attributes cover:

- **Customer Demographics:** Age, education, marital status, income, and household information.
- **Purchase Behaviour:** Spending on wine, fruits, meat, fish, sweets, and gold products.
- **Purchase Frequency:** Website, catalog, store, and discount purchases.
- **Customer Engagement:** Website visits and customer response.
- **Customer Feedback:** Recency of last purchase and complaints.

Dataset file: `smartcart_customers.csv`

## Project Workflow

### 1. Data Loading and Exploration
- Load the customer dataset using Pandas.
- Explore the dataset and understand its structure.
- Check missing values and data distributions.

### 2. Data Preprocessing
- Handle missing income values using median imputation.
- Engineer new features such as Age, Customer Tenure, Total Spending, and Total Children.
- Group education and living-status categories.
- Remove unnecessary columns.
- Identify and handle outliers.
- Encode categorical variables using One-Hot Encoding.

### 3. Feature Scaling
Apply StandardScaler to standardize the features before clustering.

### 4. Dimensionality Reduction
Use Principal Component Analysis (PCA) to reduce the scaled dataset to three principal components for visualization and clustering.

### 5. Finding the Optimal Number of Clusters
Use:
- Elbow Method
- Silhouette Score
- KneeLocator

The Elbow Method identifies 4 as the selected number of clusters in this implementation.

### 6. Customer Clustering

Two clustering algorithms are implemented:

**K-Means Clustering**
- Divides customers into four clusters.
- Uses the PCA-transformed features.
- Uses random_state=42 for reproducibility.

**Agglomerative Clustering**
- Uses four clusters.
- Applies Ward linkage.
- Groups customers based on hierarchical similarity.

### 7. Cluster Analysis and Visualization
- Visualize clusters using 3D scatter plots.
- Analyze the distribution of customers across clusters.
- Compare income and spending patterns.
- Generate cluster-wise average feature summaries.

## Results and Observations

The implementation identifies four customer clusters using both K-Means and Agglomerative Clustering.

The Agglomerative Clustering results show differences in customer characteristics:

- **Cluster 0:** Lower average income and spending, with relatively higher website visits.
- **Cluster 1:** Higher average income and spending, with strong catalog and store purchasing activity.
- **Cluster 2:** Lower average income and spending, with relatively higher website visits.
- **Cluster 3:** Higher average income and spending, with strong purchasing activity and the highest average customer response among the four clusters.

These observations are based on the cluster-wise mean values generated by the notebook.
